## 第一題

（7 分）設三角形 $ABC$ 滿足 $\cos A : \cos B : \cos C = 1 : 1 : 2$。將 $\sin A$ 表示為 $\sqrt[s]{t}$，其中 $s$ 為正整數，$t$ 為正有理數且為最簡分數。則 $s + t = $？（化為最簡分數）

## 第二題

甲和乙兩人分別擲 $n$ 個公平的硬幣，並以 $X$ 和 $Y$ 記兩個人投擲出正面向上的硬幣個數。假設兩人擲硬幣是互相獨立的實驗。

（a）（3 分）$n = 5$ 時，$X = Y$ 的機率是多少？（化為最簡分數）

（b）（4 分）$n = 6$ 時，$X = Y + 1$ 的機率是多少？（化為最簡分數）

## 第三題

令 $M$ 為四位數之正整數。將 $M$ 的四個數字反過來寫出一個新的四位數 $N$（例如：將四位數 $1234$ 的四個數字反過來寫，變成 $4321$）。令 $C$ 為 $M$ 的各位數的數字和。已知 $M, N$ 與 $C$ 滿足下列性質：

- 令 $d$ 為 $M - C$ 與 $N - C$ 的最大公因數，且 $d < 10$。
- $\dfrac{M - C}{d}$ 與 $\dfrac{N}{2} + 1$ 的整數部分相同。

（a）（3 分）$d = $？

（b）（4 分）若滿足上述性質的 $M$ 共有 $m$ 個，且最大的值為 $M_{\max}$，則 $(m, M_{\max}) = $？

## 第四題

（7 分）令 $\mathbb{N}$ 表示所有正整數的集合。已知滿足

$$1 \leq a \leq b \text{ 且 } \dfrac{a^2 + b^2 + a + b + 1}{ab} \in \mathbb{N}$$

的所有正整數解 $(a, b) = (a_n, a_{n+1})$，$\forall n \in \mathbb{N}$，其中 $a_n$ 的值由下列遞增的遞迴關係唯一決定：

$$a_{n+2} = p \, a_{n+1} + q \, a_n + r.$$

則 $(p, q, r) = $？

## 第五題

設 $S$ 為所有 $\{1, 2, 3, 4, 5, 6, 7, 8\}$ 的排列所成的集合。

（a）（2 分）對任一個 $\sigma = \sigma_1 \sigma_2 \cdots \sigma_8 \in S$，計算下列的乘積和：

$$T = \sigma_1 \sigma_2 + \sigma_3 \sigma_4 + \sigma_5 \sigma_6 + \sigma_7 \sigma_8.$$

則對 $S$ 內的所有元素，所得的 $T$ 的算術平均數為？

（b）（5 分）在 $S$ 中，滿足「對所有的 $k = 1, 2, \ldots, 7$，$k$ 的後一個數字必定不是 $k + 1$」的排列共有多少個？
