## 第一題

（7 分）在 $\triangle ABC$ 中，$\angle B = 90^\circ$，線段 $AB > BC$。今有 $\triangle A_iBC$（$i = 1, 2, \cdots, n$）與 $\triangle ABC$ 相似（頂點不一定對應）。則 $n + 2018$ 的最大值為？

## 第二題

（7 分）將 $1, 2, \cdots, 2018$ 這 2018 個數任意排成一列，得到一個數 $A$。則以 3 除 $A$ 的餘數為？

## 第三題

（7 分，下界 3 分、上界 4 分）設 $\triangle ABC$ 為銳角三角形，$H$ 為其垂心。射線 $AH, BH, CH$ 分別交 $\triangle ABC$ 的外接圓於點 $A', B', C'$。試求最佳的常數 $L$ 與 $U$，使得

$$L \leq \dfrac{AH}{AA'} + \dfrac{BH}{BB'} + \dfrac{CH}{CC'} < U$$

對所有銳角三角形 $ABC$ 恆成立。

## 第四題

數列 $\{a_n\}$ 定義如下：

$$a_1 = 1, \quad a_{n+1} = \sqrt{a_n + n^2}, \quad n = 1, 2, \cdots.$$

其中 $[x]$ 表示不大於實數 $x$ 的最大整數。

（a）（2 分）則 $[a_{2019}]$ 之值為？

（b）（5 分）則 $[a_1^2] + [a_2^2] + \cdots + [a_{20}^2]$ 之值為？

## 第五題

（7 分）試求最小正整數 $n$，使得任意 $n$ 個正整數中，必存在其中 15 個數，其總和能被 15 整除。

## 第六題

令 $\mathbb{N}$ 表示所有正整數所成的集合。函數 $f : \mathbb{N} \cup \{0\} \to \mathbb{N} \cup \{0\}$ 滿足：對任意兩個相異的正整數 $a, b$，恆有

$$f(a) + f(b) - f(a + b) = 2019.$$

（a）（2 分）則 $f(0)$ 之值為？

（b）（5 分）設 $a_1, a_2, \cdots, a_{100}$ 為 100 個兩兩相異的正整數。則

$$f(a_1) + f(a_2) + \cdots + f(a_{100}) - f(a_1 + a_2 + \cdots + a_{100})$$

之值為？

## 第七題

（7 分）設正整數 $k$ 滿足 $1 < k < 100$。對 $1, 2, \cdots, 100$ 的任一個排列 $a_1, a_2, \cdots, a_{100}$，取最小的 $m > k$，使得 $a_m$ 小於 $a_1, a_2, \cdots, a_k$ 中至少 $(k - 1)$ 個數。已知滿足 $a_m = 1$ 的排列個數恰為 $\dfrac{100!}{4}$。假設符合此條件的 $k$ 值恰為 $a$ 或 $b$（其中 $a < b$）。則 $a, b$ 之值為？
