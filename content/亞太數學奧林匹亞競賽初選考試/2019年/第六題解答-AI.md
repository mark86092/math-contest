**題目**：函數 $f : \mathbb{N} \cup \{0\} \to \mathbb{N} \cup \{0\}$ 滿足：對任意兩個相異的 $a, b$，恆有

$$f(a) + f(b) - f(a + b) = 2019.$$

（a）求 $f(0)$ 之值。

（b）設 $a_1, a_2, \cdots, a_{100}$ 為 100 個兩兩相異的正整數，求

$$f(a_1) + f(a_2) + \cdots + f(a_{100}) - f(a_1 + a_2 + \cdots + a_{100})$$

之值。

## (a) 求 $f(0)$

取 $a$ 為任意正整數、$b = 0$（兩者相異），代入關係式：

$$f(a) + f(0) - f(a + 0) = 2019,$$

左邊的 $f(a)$ 與 $f(a+0) = f(a)$ 相消，得

$$f(0) = 2019.$$

## (b) 求 $f(a_1) + \cdots + f(a_{100}) - f(a_1 + \cdots + a_{100})$

不失一般性，將這 100 個數重新排序，使得 $a_1 > a_2 > \cdots > a_{100}$（重排不影響所求之值）。

令部分和 $S_k = a_1 + a_2 + \cdots + a_k$。關鍵觀察：對每個 $1 \le k \le 99$，

$$S_k \ge a_1 > a_{k+1},$$

所以 $S_k$ 與 $a_{k+1}$ 是兩個**相異**的正整數，可以套用題目的關係式：

$$f(S_k) + f(a_{k+1}) - f(S_k + a_{k+1}) = 2019,$$

也就是

$$f(S_k) + f(a_{k+1}) - f(S_{k+1}) = 2019, \quad k = 1, 2, \cdots, 99.$$

將這 99 條式子全部相加，中間的 $f(S_2), f(S_3), \cdots, f(S_{99})$ 逐項對消（telescoping），剩下

$$f(S_1) + \sum_{k=2}^{100} f(a_k) - f(S_{100}) = 99 \times 2019.$$

由於 $f(S_1) = f(a_1)$，即得

$$f(a_1) + f(a_2) + \cdots + f(a_{100}) - f(a_1 + a_2 + \cdots + a_{100}) = 99 \times 2019 = 199881.$$

## 附註：$f$ 的一般形式

事實上可以完全刻劃 $f$。令 $g(n) = f(n) - 2019$，則關係式化為：對相異的 $a, b$，

$$g(a + b) = g(a) + g(b).$$

由 $g(1) + g(4) = g(5) = g(2) + g(3)$、$g(4) = g(1) + g(3)$ 可推出 $g(2) = 2g(1)$，再配合 $g(n+1) = g(n) + g(1)$（$n \ge 2$）歸納可得 $g(n) = n \cdot g(1)$ 對所有 $n \ge 1$ 成立。因此

$$f(n) = cn + 2019, \quad n \ge 1$$

（其中 $c = f(1) - 2019$ 為使值域落在 $\mathbb{N} \cup \{0\}$ 的任意整數，例如任意 $c \ge 0$ 皆可），且 $f(0) = 2019$。

驗算 (b)：$\sum_{i=1}^{100} f(a_i) - f\left(\sum a_i\right) = \left(c \sum a_i + 100 \times 2019\right) - \left(c \sum a_i + 2019\right) = 99 \times 2019 = 199881$，與前述結果一致。

## 結論

- （a）$f(0) = 2019$
- （b）$99 \times 2019 = 199881$
