## 第二題

設 $c$ 為非零的整數，定義數列 $a_1, a_2, a_3, \cdots$ 為 $a_1 = 2$ 且

$$a_{n+1} = c a_n + \sqrt{(c^2 - 1)(a_n^2 - 4)},\quad n = 1, 2, 3, \cdots.$$

試證：$a_{2000}$ 是整數。

## 第三題

設數列 $\{a_n\}$ 滿足 $\dfrac{a_n + a_{n+2}}{2} \leq a_{n+1}$，$n$ 是任意正整數。試證

$$\frac{a_1 + a_3 + \cdots + a_{2n+1}}{n+1} \leq \frac{a_2 + a_4 + \cdots + a_{2n}}{n}.$$
