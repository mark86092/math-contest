## 第一題

設 $A, B, C, R, S, T$ 為圓 $O$ 上的相異點，其中 $A, R$ 在 $\overline{BC}$ 的同側，且 $\overline{AB} = \overline{AC}$，$\overline{RB} > \overline{RC}$。已知 $\overline{RS} = \overline{RT} = \sqrt{\overline{RB} \cdot \overline{RC}}$。試證：

1. （4 分）$\overline{RB} + \overline{RC} < 2\overline{AB}$。
2. （8 分）若 $\angle BRC \geq 90^\circ$，則 $\triangle RBC$ 面積大於 $\triangle RST$ 面積。

## 第二題

（12 分）在坐標空間中，有一直線 $L: \dfrac{x}{2} = \dfrac{y}{2} = z - 1$ 及兩點 $A(1, 2, 1)$, $B(0, 1, -1)$。若點 $P$ 在直線 $L$ 上移動，求 $\overline{AP} + \overline{BP}$ 的最小可能值。

## 第三題

（12 分）設 $f(x)$ 為定義在所有正實數上的實數值函數。已知 $f(1) = 2$，且對任意正實數 $x, y$，恆有

$$f\left(\sqrt{x^2 + y^2}\right) = \frac{f(x)f(y)}{f(x) + f(y)}.$$

試求 $f(7)$ 之值。

## 第四題

1. （4 分）設 $\alpha, \beta, \gamma$ 為三銳角，且 $\alpha + \beta + \gamma = 90^\circ$。試證：

$$\tan\alpha \tan\beta + \tan\beta \tan\gamma + \tan\gamma \tan\alpha = 1.$$

2. （9 分）試找出所有的正實數組 $(x, y, z)$，滿足方程組

$$\begin{cases} 2\left(x + \dfrac{1}{x}\right) = 3\left(y + \dfrac{1}{y}\right) = 4\left(z + \dfrac{1}{z}\right), \\ xy + yz + zx = 1. \end{cases}$$
